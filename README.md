# 邢鹏程的个人简历

适配电脑和手机的静态简历页面。使用原生 HTML、CSS 和 JavaScript，无需安装依赖或构建。

## 本地预览

直接打开 `index.html`，或在此目录运行 `python -m http.server 8080`，访问 `http://localhost:8080`。

## 发布到 GitHub Pages

1. 创建公开仓库 `xingpengcheng417.github.io`，将本目录文件推送到 `main` 分支。
2. 打开仓库 Settings → Pages。
3. Source 选择 Deploy from a branch，分支选择 main，目录选择 /(root)，保存。
4. 等待部署完成，访问[个人简历主页](https://xingpengcheng417.github.io/)。

## 更新内容

- `index.html`：个人介绍、技能、项目、工作和教育经历、联系方式。
- `styles.css`：布局、响应式样式、深浅主题和打印样式。
- `script.js`：主题切换、项目筛选和导航状态。
- `assets/resume.pdf`：下载的原始 PDF 简历，替换此文件即可更新。

网页内容根据用户提供的原始 PDF 简历及 HES 工作日报、阶段功能成果总结整理。HES 项目时间由本人确认为 2024 年 8 月至今；本次收录的 HES 成果覆盖 2026 年 7—10 月，不将测试规模当作生产指标，也不将仅定位或未交付事项列作完成成果。公司名称和任职名称未据此补造。

下载文件仍是原始 PDF，尚未包含 HES 经历，页面已明确标注。两份 HES 原始工作材料不随网站公开上传。页面及 PDF 包含简历中的联系电话、邮箱等信息，公开部署后访客可以查看与下载。
